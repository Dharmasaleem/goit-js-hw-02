# goit-js-hw-02

Домашнє завдання №2 з JavaScript: розгалуження та цикли.

## Завдання

- `task-1.js` — перевірка можливості оплати замовлення.
- `task-2.js` — форматування повідомлення.
- `task-3.js` — перевірка повідомлення на спам.
- `task-4.js` — розрахунок вартості доставки за допомогою `switch`.
